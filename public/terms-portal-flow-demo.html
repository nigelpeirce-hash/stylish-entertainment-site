T&C Portal Flow Demo

Where and how the personalised T&C acceptance appears in the client portal

Flow Where it shows State: Pending State: Accepted Print / PDF

1. Flow

1

Client logs in → lands on client dashboard (/client/dashboard)

2

Booking card → each event shows a card with tabs: Overview | Music | Budget | Contract

3

Contract tab → default/first tab when terms not yet accepted. Shows personalised T&C document

4

Other tabs gated → Overview, Music, Budget show a banner: "Please accept Terms in Contract tab to continue"

5

Client accepts → checkbox + type name → "Accept & Sign" → API stores acceptance, sends email

6

All tabs unlock → client can use Music, Budget, etc. Contract tab shows confirmation + Print button

Email Autoresponders & Schedule

Journey emails and when they send, from last action. Stylish Entertainment.

All automated and manual journey emails, in order. Schedule from last action shows when each email fires relative to the previous step or event date. Cron runs daily at 9:00 AM (/api/cron/email-journey).

Journey emails (order & trigger)

1

Enquiry Auto-Responder

Automated
Schedule from last action Immediate
Trigger On contact form submit

Thank-you email with brochure link. Sent as soon as the enquiry is received.

2

Gentle Reminder (3-Day)

Automated
Schedule from last action 3 days after
Trigger 3 days after Enquiry Auto-Responder; only if status still pending/inquiry

Follow-up if no booking confirmed. Uses lastEmailSentAt and emailsSent.enquiryAutoresponder.

3

Booking Confirmation

Manual
Schedule from last action Manual send
Trigger After deposit / admin confirms booking

Sent manually from admin when booking is confirmed. May include portal invite.

4

4-Week Check-in

Automated
Schedule from last action 28 days before event
Trigger Event date is 28–29 days away; requires booking confirmation already sent

Pre-event check-in. Only sent if emailsSent.bookingConfirmation exists and fourWeekCheckin not yet sent.

5

Week-of Excitement

Automated
Schedule from last action 7 days before event
Trigger Event date is 6–7 days away

Excitement email one week before the big day. Status confirmed or pending.

6

Final Chase

Automated
Schedule from last action 2–3 days before event
Trigger Event date is 2–3 days away; tokenized magic link (no login)

Last reminder before event with magic link to client portal.

7

Post-Wedding Magic

Automated
Schedule from last action 3 days after event
Trigger Event date was 3 days ago; status confirmed or completed

Thank-you and follow-up after the event.

8

Portal Reminder

Automated
Schedule from last action 3+ days after portal invite
Trigger Portal invite sent 3+ days ago, no reminder sent yet; booking confirmed with portal token

Resends magic link if client hasn’t used the portal yet.

Tracking: All sends are recorded in Booking.emailsSent (e.g. enquiryAutoresponder, threeDayReminder, fourWeekCheckin, weekOfExcitement, finalChase, postWeddingMagic, portalReminder). lastEmailSentAt is updated when cron sends an email.

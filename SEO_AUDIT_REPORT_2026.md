## 4. ROBOTS.TXT

Current rules:

```
allow: /
disallow: /admin/, /api/, /client/, /demo-, /login, /register
sitemap: https://www.stylishentertainment.co.uk/sitemap.xml
```

- `/demo-` blocks `demo-booking-flow`, `demo-client-dashboard`, etc. ✓
- `/demo/` (portal-preview, client-portal, guest-requests-workflow) is **allowed** and could be indexed.

**Recommendation:** Add `/demo/` to `disallow` if these are internal demos only.

## 5. CANONICAL URL INCONSISTENCY

- **`lib/metadata.ts`** `baseUrl`: `https://stylishentertainment.co.uk` (no www)
- **Root layout** `metadataBase`: `https://www.stylishentertainment.co.uk` (with www)

Pages using `createMetadata` will get canonicals without `www`; Next.js default metadata uses `www`. Canonicals should match the canonical domain.

**Recommendation:** Use one canonical domain (usually `www`) everywhere. Update `lib/metadata.ts` to `https://www.stylishentertainment.co.uk`.

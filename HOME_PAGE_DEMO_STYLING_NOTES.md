# Home Page Demo – Styling Reference (Frozen)

This demo is **frozen** as the design reference. No further changes to the demo; use it as the source of truth when applying styles to the live site.

## Demo file

- **Path:** `public/home-page-demo.html`
- **View:** `http://localhost:3001/home-page-demo.html` (with dev server) or open the file in a browser.

## Frozen design summary

- **Vibe:** Great Gatsby / Art Deco – very black, luxe, champagne gold.
- **Typography:** Cinzel (headings), Lora (body), Cormorant Garamond (serif accents).
- **Colours:** Black/charcoal panels, champagne gold (`#E6C84A`) accents, lighter grey hero band.
- **Details:** Gold orbs, gold borders/dividers, card hovers with gold glow.

## Next step

Apply this design to the live site: update `app/page.tsx`, `app/globals.css`, and Tailwind config to match the demo’s tokens and styles. Iterate on the live app from there, not on the demo.

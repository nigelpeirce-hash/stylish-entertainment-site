# Before & After Room Transformation — Use on Instagram

Instagram can’t run the interactive slider (the line you drag). To get that **same moving-line effect** on Instagram, **record a short video** of the slider and post it as a **Reel**.

---

## Option A: Record the slider (moving line) for Instagram Reels

**1. Open the slider in a browser**

- **From your live site:**  
  Go to: `https://yourdomain.com/room-transformation/`  
  or, locally: `http://localhost:3001/room-transformation/`

- **Standalone file (no server):**  
  In Finder, go to your project → `public` folder → double‑click **`before-after-slider.html`**  
  It opens in your default browser with the same before/after slider and draggable line.

**2. Record your screen**

- **Mac:** QuickTime Player → File → New Screen Recording → select the browser window. Drag the slider back and forth a few times (about 10–15 seconds), then stop.
- **Windows:** Xbox Game Bar (Win + G) or another screen recorder. Record the browser while you drag the slider.

**3. Post as an Instagram Reel**

- Trim to 10–15 seconds if needed.
- Add a short caption, e.g. *“Before → After. Same room. Drag to see the full transformation.”*
- Optional: add “Link in bio” if you want to send people to your room-transformation page.

That way followers see the **line moving back and forth** exactly like on your site, just as a video.

## 2. Use on Instagram

**Carousel (recommended)**  
- Post 2 images: first “Before”, second “After”.  
- Add a short caption, e.g. *“Before → After. Same room, full transformation. [Venue styling / lighting / your service]. Link in bio for more.”*

**Single post**  
- Use a layout app (e.g. Canva, Unfold, PicCollage) to put Before and After side by side or with a “Before | After” label, then post that single image.

**Reels**  
- Use the same two images in a simple Before → After transition (e.g. 2–3 seconds each) with text overlay “Before” / “After” and optional music.

**Stories**  
- One image per story, or use a template that shows both in one story frame.
